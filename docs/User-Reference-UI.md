客服分類、防詐節省金額、Pivot 等沒有完整模型或 API 的能力，明示缺口，不填入參考截圖的數字。功能盤點以新增樣式前的程式為基準，見 [Benamic 後台差異分析](Benamic-Backend-Gap-Analysis.md)。

## 保留與限制

- 原 `App.tsx` 與既有樣式不修改；入口依 pathname 載入參考版本。參考 CSS 以容器 class 限定，並隨參考頁面延遲載入。
- 既有申請表與修訂／附件／版本更新功能共用；參考版調整外觀，仍保留本系統的步驟與資料驗證。
- 仍只提供既有五國 DE／FR／IT／ES／NL、EUR；參考活動框架以截圖英文為主，沿用的申請與營運元件保留英文／繁體中文切換。未擴增截圖的全部市場或完整多語翻譯。
- 通路設定沒有 Logo 欄位，因此通路區顯示既有名稱；不製造 Logo 或未知外部連結。FAQ 未展開答案以設定內容為準。
- 原始主視覺含歷史 €180 字樣，只在已有相應設定的 Q1 參考活動使用。活動欄位與申請計算仍由 API 決定。
- UAT 沿用明確的開發環境登入；Google／AORUS 正式登入、銀行 API 與正式寄信仍未連接。
